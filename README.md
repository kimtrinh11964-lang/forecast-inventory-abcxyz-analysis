# forecast-inventory-abcxyz-analysis
# Forecast Accuracy and Inventory Management Using ABC–XYZ Analysis

## Project Overview
This project evaluates forecast accuracy and inventory management effectiveness
using sales, demand, and inventory data at the product level.
The analysis aims to support better inventory control and replenishment decisions.

## Business Objectives
- Evaluate forecast accuracy using WMAPE and Forecast Error.
- Measure inventory management efficiency using Days of Supply (DOS).
- Apply ABC–XYZ classification to prioritize inventory control at the store level.

## Data Source
The dataset used in this project is publicly available on Kaggle:
https://www.kaggle.com/datasets/atomicd/retail-store-inventory-and-demand-forecasting

## Methodology
- Data aggregation with pandas.
- Forecast accuracy evaluation (WMAPE, Forecast Error).
- ABC–XYZ inventory classification.
- Inventory efficiency analysis using DOS (Days of Supply).

## Tools & Technologies
- Python.
- Pandas, Matplotlib, Seaborn.
- Google Colab.

## Scope
- 5 stores.
- 20 products.
- 5 product categories.

## Key Outputs
- Forecast accuracy performance by product and store
- Inventory classification (ABC–XYZ)
